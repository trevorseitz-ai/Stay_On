# Stay On Driving 1.0.2: release notes and App Store listing text

App changes since 1.0.1 (build `202611061430`):
- The Sentry environment fix (`5aac4b8`, PR #23): simulator and Debug builds now report as their own Sentry environments. Players won't notice it.
- The version bump to 1.0.2, build `202611182248`.

This release mainly ships new App Store listing text (ASO). Apple locks name, subtitle, keywords and description on a live version, so they can only change with a new version.

## What's New

```
• Stability and crash-reporting improvements.
• Minor fixes.
```

## Listing text

Apple's search uses only name, subtitle and keywords, and it combines them, so no word should appear in more than one of them. Description doesn't affect search but drives downloads.

| Field | 1.0.1 | 1.0.2 |
|---|---|---|
| Name (30) | `Stay On Driving` | `Stay On Driving: Neon Racer` (27) |
| Subtitle (30) | `Retro Arcade Driving Challenge` | `Endless Retro Arcade Racer` (26) |
| Keywords (100) | `driving,racing,arcade,road,car,retro,reflex,steering,challenge,game` (67) | `synthwave,outrun,highway,road,car,steer,swerve,reflex,tap,casual,offline,80s,vaporwave,speed,lane` (97) |

### Description

```
Stay On Driving is a neon, synthwave-style arcade driving game with one-touch controls: hold to steer left, release to steer right. Stay on the road as long as you can.

The farther you drive, the faster it gets, and the road grows narrower and twistier. React quickly, hold your line, and see how far you can go.

Features:

• One-touch steering: hold for left, release for right
• Easy, Medium and Hard starting levels
• An endless road that keeps getting harder
• Synthwave soundtrack and retro neon visuals
• Your Top 5 best runs, saved on your device
• Plays offline, no account needed
• Free with ads; remove them with a one-time purchase

How far can you stay on?
```
